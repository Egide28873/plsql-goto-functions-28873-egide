# Reflection

## 1. What I learned about GOTO

I learned that GOTO is used to move from one part of a PL/SQL program to another part using a label. I also learned that GOTO cannot be used everywhere in a PL/SQL block.

## 2. What I learned about Functions

I learned how to create and use functions in PL/SQL. A function can take input, do some work, and return a result.

In my project, I created functions for annual salary, years of service, tax, and department name.

## 3. What I learned about using Functions in SQL

I learned that PL/SQL functions can also be used in a SELECT statement. This helped me to display employee information together with calculated values.

## 4. What I learned about Exception Handling

I learned that exception handling is used when an error happens in a PL/SQL program. For example, I used NO_DATA_FOUND when an employee ID does not exist.

## 5. Challenges I faced

At first, I had some difficulty understanding GOTO and labels. I also had some problems when creating and testing the functions.

## 6. How I solved the problems

I solved the problems by checking my code, running it in Oracle SQL Developer, and correcting the errors. I also tested the functions with different employee IDs and salary values.

## 7. What I learned from this assignment

This assignment helped me understand PL/SQL better. I learned how to use GOTO, functions, SELECT statements, and exception handling in a practical project.

## 8. AI Usage

I used an AI assistant to help me understand some PL/SQL concepts and to guide me when I had errors. I tested the code myself in Oracle SQL Developer and made sure I understood how the code works.
